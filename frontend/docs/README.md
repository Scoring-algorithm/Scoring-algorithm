# Transaction Scoring System — Frontend

SPA для системы транзакционного скоринга.

## Запуск

1. Установить Node.js 20+ (https://nodejs.org)
2. Открыть терминал в папке проекта
3. Выполнить: npm install
4. Выполнить: npm run dev
5. Открыть http://localhost:5173

## Стек
- React + TypeScript
- Vite
- React Router

## Реализовано
- Модуль ручной проверки транзакций (monitoring)
- Просмотр объяснений скоринговой модели
- Фильтры и поиск
