# Архитектура фронтенда

## Структура папок
- `src/components/` — переиспользуемые UI-компоненты
- `src/pages/` — страницы (Транзакции, Пороги, Дашборд, Аудит)
- `src/types/` — типы TypeScript
- `src/mocks/` — моковые данные для разработки без бэкенда

## Компоненты
- **Layout** — общий каркас: меню слева + контент
- **Button** — кнопка с вариантами (primary/danger/secondary)
- **Badge** — цветной бейдж статуса транзакции

## Страницы
- **TransactionsPage** — список транзакций, фильтры, модалка
- **ThresholdsPage** — настройка порогов (в разработке)
- **DashboardPage** — аналитика (в разработке)
- **AuditPage** — журнал действий (в разработке)
