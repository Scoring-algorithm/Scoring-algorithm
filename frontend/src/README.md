# Transaction Scoring System — Frontend

SPA для системы транзакционного скоринга.

## Стек
- React + TypeScript
- Vite (сборщик)
- React Router (роутинг)

## Запуск
1. Установить Node.js 18+
2. `npm install`
3. `npm run dev`
4. Открыть http://localhost:5173

## Реализовано
- Базовая структура приложения, роутинг, layout
- Модуль ручной проверки транзакций (monitoring)
- Просмотр объяснений скоринговой модели

## Статус
Работа на моках (src/mocks/). Интеграция с бэкендом — следующий этап.
